# 03. 안전 규칙

사람과 에이전트는 모든 단계에서 다음을 지킨다.

1. API 키, OAuth 토큰, 로그인 정보를 읽거나 복사하거나 출력하지 않는다. 로그인 상태는 사람이 직접 화면에서 확인한다.
2. 승인 대화상자를 자동으로 통과시키거나 trust 질문을 우회하지 않는다. 권한 검사를 건너뛰는 `skip-permissions`류 옵션도 사용하지 않는다. 승인 창이 뜨면 사람이 판단하고 답한다.
3. 사람의 설정 파일을 고치기 전에는 대상 파일 경로와 바뀔 내용을 미리 보여 준다. `~/.claude/settings.json`, Codex 설정, 셸 프로필, Herdr 설정도 포함한다. 적용은 사람이 직접 한다.
4. `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `HOME`을 바꾸지 않는다. 기존 로그인과 사용자 설정을 그대로 사용한다.
5. 자식 프로세스를 열 때 환경에서 `ANTHROPIC_API_KEY`와 `OPENAI_API_KEY`를 제거한다. 키 값은 확인하거나 기록하지 않는다.
6. 외부 게시와 공유는 내용을 보여 주고 사람의 승인을 받은 뒤에 한다.

불명확하거나 안전 규칙을 지키기 어렵다면 멈추고 이유와 현재까지의 결과를 남긴다.
