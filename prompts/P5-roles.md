# P5. 역할 지시문

목적: 5개 역할 지시문을 역할 폴더에 준비한다.

## 붙여 넣을 프롬프트

```text
docs/03-safety-rules.md를 지킨다. reference/roles/에 디렉터, 리드, 코딩 작업자, 검토 작업자, 조사 작업자의 지시문 5개가 있는지 확인한다. 빠진 파일이 있으면 목록을 보고하고 멈춘다. bench.yaml의 `roles` 폴더(PORT/roles)에 5개 파일을 복사한다. 채울 자리표시자는 `<정책 파일 경로>` 하나다. bench.yaml의 `policy` 값으로 바꾼다. 명령 예시 안의 `<모델명>`·`<작업 지시>` 같은 `<…>`는 에이전트가 쓸 때 채우는 입력칸이므로 그대로 둔다. 역할 파일의 `python3 "$BENCH"`를 이 PC의 Python 이름으로 바꿀지 사람에게 묻고, 바꾸면 5개 파일에 같은 값으로 바꾼다. 확인되지 않은 값은 지어내지 않는다. 기존 파일을 덮어써야 하거나 역할 폴더가 사람 설정 위치라면 경로와 변경 내용을 미리 보여 주고 사람이 직접 적용할 때까지 멈춘다. 복사와 변경 결과, 남은 자리표시자를 보고한다.
```

## 확인할 결과

역할 폴더에 각 역할의 지시문이 1개씩 있는지 확인한다. 자리표시자의 변경 내용과 미확인 값이 보여야 한다.

## 멈출 때

5개 원본이 모두 없거나 필요한 값을 확인하지 못하면 누락 목록과 이유를 남기고 멈춘다.
