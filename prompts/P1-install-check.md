# P1. 설치 확인

목적: 필요한 프로그램과 Herdr 스페이스 id를 읽기 전용으로 확인한다.

## 붙여 넣을 프롬프트

```text
읽기 전용으로 설치 상태를 확인한다. docs/03-safety-rules.md를 지킨다. herdr-app, hc, claude, codex, Python(python, py -3, python3 중 되는 것), git, pwsh의 실행 가능 여부, 버전, 실행 파일 경로를 확인하고 결과를 표로 정리한다. 로그인 정보나 환경변수의 비밀값은 읽거나 출력하지 않는다. Claude Code와 Codex의 구독 로그인 상태는 사람이 각 화면에서 확인하도록 안내한다. Herdr 스페이스 id를 표시하는 방법을 설치된 프로그램의 도움말 또는 앱 화면에서 확인하고, 확인한 방법과 id를 표에 적는다. 명령 이름이나 방법을 찾지 못하면 추측하지 말고 '확인 필요'로 표시한다. Python에서 `import yaml`과 `from zoneinfo import ZoneInfo; ZoneInfo('Asia/Seoul')`이 되는지도 확인한다. 파일과 설정은 바꾸지 않는다. 결과 표는 답으로만 출력한다. P2에서 PORT/notes.md를 만든 뒤 그 표를 옮겨 적는다.
```

## 확인할 결과

각 도구의 버전과 실행 경로가 표에 나와야 한다. 스페이스 id의 확인 방법과 결과 또는 '확인 필요'가 보여야 한다. 로그인 화면은 사람이 직접 확인한다.

## 멈출 때

필수 프로그램이 없거나 스페이스 id를 확인할 수 없으면 해당 결과를 남기고 설치 또는 확인 후 다시 시작한다.
