# P0. 맥락 확인

목적: 묶음의 목적과 이식 범위를 파악한다.

## 붙여 넣을 프롬프트

```text
작업 폴더를 묶음의 루트로 보고 README.md, docs/01-what-is-this.md, docs/02-platform-points.md, docs/03-safety-rules.md를 읽는다. docs/03-safety-rules.md를 지킨다. 작업대의 목적, 구성 요소, Windows 이식의 주요 위험과 확인되지 않은 부분을 요약한다. 빠진 파일이 있으면 그 경로를 보고한다. 파일이나 설정은 바꾸지 않고 명령도 읽기 전용으로만 실행한다.
```

## 확인할 결과

작업대의 역할, Windows에서 이식할 부분과 미확인 사항이 요약되어야 한다. 빠진 문서가 있으면 목록에 보여야 한다. 변경 파일은 없어야 한다.

## 멈출 때

문서를 읽을 수 없거나 설명이 실제 묶음과 다르면 원인을 남기고 멈춘다.
